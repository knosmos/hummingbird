Custom STM32 flight controller for MIT Design Build Fly 2025

### Features

- STM32F103C8T6 microprocessor
- Altimeter and IMU
- 2x Servo PWM
- 12V / 5V LDO regulators
- MOSFET LED drive circuits
- Hall effect sensor input
- GPS and magnetometer input
